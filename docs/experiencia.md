# Experiencia y tono

## Intención

El portafolio no es una landing de “hire me / corporate friendly”.  
Es una **experiencia visual de videojuego** que **cuenta una historia** y busca **relación** con el visitante (anti “empresa de esclavos corporativos”), no un CV animado.

Detalle del mapa: [mundo.md](./mundo.md). Arte: [arte.md](./arte.md).

## Profundidad (entre B y C, con arena)

| Nivel | Qué es | Encaje |
|-------|--------|--------|
| A — Solo estética | HUD y pantallas, navegación web normal | Demasiado poco |
| **B — Exploración** | Mapa; zonas = secciones | Base (pasillo, hub) |
| **C — Jugable** | Movimiento, dash, diálogos, minijuegos, **jefe** | Objetivo actual |
| RPG abierto | Quests largas, grind de XP | Fuera |

Motor: **Phaser**.

### Arco deseado (borrador)

1. Avatar (1ª visita) → hub oscuro.
2. **Entrar al pasillo** → reciben **abalorio de dash** (primer vínculo).
3. Pasillo (frases + música; **textos después**) → umbral.
4. **Centro — Quién soy**: grafo **blanco** + Imoogi.
5. **Izquierda — Hábitats**: Elven forest (cita Hilo → companion) + anillo…
6. **Norte — Arena**…
7. **Derecha — Stitch (visión)**: marco scripted; más denso si Hilo te acompaña.

Sin Hilo el recorrido vale; con Hilo **lore del detrás de cada proyecto**. La cita enseña algo (p. ej. **Woven**): memoria en conversación, no quiz; si el cierre falla, Hilo se entristece y no acompaña. **No** se piden API keys.

Primera vista: oscuridad, sonido, caminar, primer regalo — no stats ni cards.

## Dirección visual

Detalle: [arte.md](./arte.md).

- Top-down **2D ilustrado**; negro crepuscular; vinotinto + violeta liminal.
- Tipografía **manual**; Imoogi y grafo blanco como arriba.
- HUD mínimo: zona, interacción, dash/equipo.

## Analítica en la experiencia

Las stats son para **entender uso**, no para vigilancia corporativa. Eventos posibles (cuando se implemente):

- entrar al pasillo / recibir abalorio de dash
- hablar con Imoogi / abrir nodos del grafo
- entrar hábitat (arcade / deep dark / tropical techno / scifi neon / elven forest) / minijuego / click demo o repo
- recoger equipo / pelear jefe (y profundidad de patrones vista)
- zona Stitch / Hilo companion (si desbloqueado): revelaciones extra
- Elven: resultado de la conversación-cita con Hilo
